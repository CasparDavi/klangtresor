# bin/texte/ — Übersetzungen der Konsolenprogramme

Einrichtung, Aktualisieren, Starter und die Teilschritte der Einrichtung sprechen DE, EN und RU (bin/sprache.js).
Der deutsche Satz steht im Code und ist der Schlüssel: `T('Hier sind nur {mb} frei.', { mb: MB(platz) })`.
Je Programm eine Datei hier: `{ "<deutscher Satz mit {platzhaltern}>": { "en": "…", "ru": "…" } }`.
Russisch: Anrede „вы“, „клик“, „лайки“, Regeln in docs/ru/PRAVILA.md. Englisch: wie die Oberfläche (web/ui-sprache.js).
