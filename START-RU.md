# KlangTresor — для вашего собственного архива Suno

[Deutsch](START-HIER.md) · [English](START-HERE.md) · **Русский**

> **Смена названия:** до 24.08.2026 проект назывался *MySuno*. Теперь он называется **KlangTresor**: с 06.01.2026 «Suno» — зарегистрированный товарный знак Suno Inc., прямо для программ воспроизведения и обработки аудиоконтента. Там, где в цитатах и в хронике ещё стоит старое название, оно остаётся.

Это локальный архив ваших треков, опубликованных на Suno.
Он загружает вашу музыку, обложки, тексты и плейлисты на ваш компьютер
и даёт вам сайт для них, который работает в вашей домашней сети Wi-Fi —
в том числе на iPhone и iPad.

Всё остаётся у вас: никакого облака, никакой учётной записи, кроме вашего входа на Suno,
никакой базы данных. То, что вы запускаете здесь, работает на вашем компьютере
и обращается только к Suno — в одну сторону, только для чтения.

**Вам не нужно ничего вписывать и ничего настраивать.** Вашу учётную запись Suno
программа определяет сама, как только вы один раз запустите сбор.

## Быстрый путь — один скрипт делает всё

Пакет всегда доступен здесь в самой свежей версии:

    https://github.com/CasparDavi/klangtresor/releases/latest/download/KlangTresor.zip

Распакуйте его: появится папка `KlangTresor` — один уровень, не папка в папке. В ней лежат
скрипты установки. Достаточно **одного** из них — найдите строку для вашей системы
и вашего способа:

| ваша система | обычный способ | с Docker |
|---|---|---|
| **Windows** | двойной клик по `einrichten-windows.cmd` | двойной клик по `einrichten-docker-windows.cmd` |
| **macOS** | двойной клик по `einrichten-macos.command` | двойной клик по `einrichten-docker-macos.command` |
| **Linux** | `./einrichten-linux.sh` | `./einrichten-docker-linux.sh` |

Больше там ничего нет: шесть файлов установки, а также `starten-*` для последующих запусков и `aktualisieren-*` для новых версий.
У каждого файла три ступени, и каждая подхватывает следующую: сначала скрипт
вашей системы загружает Node.js (если его нет), затем управление берёт `bin/einrichten.js`
и открывает установку **как страницу в браузере**: список этапов,
индикатор выполнения, пояснения, кнопки вместо сочетаний клавиш. Если браузер не открылся,
то же самое продолжается в окне в виде текста — отвечать можно в обоих местах.
Если нужен только текст, добавьте `--text`.

Установка идёт на языке вашей системы (немецкий, русский, иначе английский);
вверху страницы установки переключатель **DE | EN\* | RU\***.

**При первом двойном клике ваша система будет возражать — это нормально:** пакет
не подписан, исходный код лежит рядом в открытом виде.

- **Windows** показывает окно «Открыть файл — предупреждение системы безопасности.
  Не удалось проверить издателя. Вы действительно хотите запустить это программное обеспечение?» —
  с пометкой «Неизвестный издатель» и красным щитом под ней. Нажмите **Запустить**.
  Если снять флажок «Всегда спрашивать при открытии этого файла», для этого файла вопрос
  больше не появится. Если вместо этого откроется синее окно SmartScreen, нажмите в нём
  «Подробнее», а затем **Выполнить в любом случае**.
- **macOS** сообщает о «неустановленном разработчике» — один раз кликните правой кнопкой → «Открыть».
  Начиная с macOS 15 пункта «Открыть» там больше нет: тогда
  «Системные настройки» → «Конфиденциальность и безопасность» → **Всё равно открыть**.

Для **последующих запусков** установка кладёт на рабочий стол ярлык «KlangTresor» с
значком; он запускает сервер и открывает браузер (Chrome, если он есть). Если вы
его удалили, возьмите из папки `starten-windows.cmd`,
`starten-macos.command` или `starten-linux.sh` — они больше
ничего не устанавливают, а только запускают.

### Установка обновления

Красная кнопка загружает с Suno новые *треки*. Новая *версия* программы
приходит с GitHub. KlangTresor проверяет её сам: при открытии страницы
и, пока она открыта, каждые 12 часов (после неудачи — через 2
часа), а также каждый раз, когда открывается окно «KlangTresor» (клик по
названию вверху). Запрос к GitHub делает сам сервер, а полученный ответ
он помнит полчаса; неизменяемая копия на флешке не спрашивает никогда.
Если есть новая версия, слева от красной кнопки появляется колокольчик; клик по нему
открывает окно с сообщением: какая версия доступна, в какой
папке работает KlangTresor и какой скрипт устанавливает обновление.
Кнопка **Показать папку** открывает эту папку в файловом менеджере — только на компьютере,
на котором работает KlangTresor. В контейнере её нет: там окно сообщает,
что нужно перейти на компьютере в папку проекта.

Чтобы установить обновление, запустите файл в той же папке, где лежит установка (там находятся `bin/`
и `library/`, а не подпапка `docker/`):

| ваша система | файл |
|---|---|
| **Windows** | двойной клик по `aktualisieren-windows.cmd` |
| **macOS** | двойной клик по `aktualisieren-macos.command` |
| **Linux** | `./aktualisieren-linux.sh` |

Клон Git: скрипт забирает `origin/main`. Установка из zip: скрипт загружает
`KlangTresor.zip` из свежего релиза и накладывает файлы программы
поверх прежних. **`library/` остаётся** — треки, изображения, звук. Если KlangTresor работает
в Docker, образ собирается заново (`compose up --build`); оверлей NVIDIA
сохраняется, если контейнер уже использует `KLANG_CUDA`.

Несохранённые изменения и ветка Git, отличная от `main`, останавливают
скрипт. После обновления один раз обновите страницу жёстко (с обходом кэша); без Docker перезапустите
сервер через `starten-*`.

### Старые версии без скрипта обновления

До версии 1.0.72 — а также со времён, когда KlangTresor ещё назывался *MySuno* —
в папке нет `aktualisieren-*`. Для этого есть пакет обновления,
всегда в самой свежей версии:

    https://github.com/CasparDavi/klangtresor/releases/latest/download/KlangTresor-Update.zip

Скопируйте `aktualisieren.js` и скрипт для вашей системы в вашу папку
KlangTresor или MySuno (туда, где лежит `library/`) и дважды кликните
по скрипту.

| ваша система | скопируйте эти два файла | затем |
|---|---|---|
| **Windows** | `aktualisieren.js` и `aktualisieren-windows.cmd` | двойной клик по `aktualisieren-windows.cmd` |
| **macOS** | `aktualisieren.js` и `aktualisieren-macos.command` | двойной клик по `aktualisieren-macos.command` |
| **Linux** | `aktualisieren.js` и `aktualisieren-linux.sh` | `./aktualisieren-linux.sh` |

Копируйте только файлы, не заменяйте папки. В пакете намеренно нет
подпапки: при копировании Finder заменяет существующую папку
`bin/`, а не объединяет её с новой — и ваша старая программа пропала бы.

После этого обновление идёт как обычно: **`library/` остаётся**, программа
обновляется, а потом в папке лежат все `aktualisieren-*`. Копия `aktualisieren.js`
удаляет себя сама после первого успешного запуска; при следующем обновлении достаточно
двойного клика. Начиная с версии 1.0.73 пакет вам не нужен — скрипт уже лежит
в папке.

**При первом запуске ваша система будет возражать**, как и при установке:

- **Windows**: «Не удалось проверить издателя» — **Запустить**. Если откроется синее окно
  SmartScreen — «Подробнее», затем **Выполнить в любом случае**.
- **macOS**: «неустановленный разработчик» — в первый раз кликните правой кнопкой →
  **Открыть**. Начиная с macOS 15 пункта «Открыть» там больше нет: тогда
  «Системные настройки» → «Конфиденциальность и безопасность» → **Всё равно открыть**.
- **Linux**: если скрипт не запускается, у него нет права на выполнение —
  `chmod +x aktualisieren-linux.sh` или `bash aktualisieren-linux.sh`.

**Клон Git** забирает `origin/main`, как обычно; скопированные файлы Git при этом
приносит сам. Если история Git происходит не с GitHub (клон времён
MySuno), вместо этого берётся zip релиза — `.git/`
остаётся, а несохранённые изменения перед этим откладываются в `git stash`.

**Только Docker, без Node на компьютере:** тогда пакет не поможет, ему нужен
Node. Скопируйте содержимое нового `KlangTresor.zip` в вашу папку
(заменяйте файлы, но никогда не всю папку целиком — в ней лежит `library/`) и
ещё раз запустите `einrichten-docker-*`. Если ещё работает контейнер `mysuno`
со времён MySuno, сначала выполните `docker stop mysuno`.

В Windows скрипты PowerShell лежат в `bin\` и вызываются из
файлов `.cmd` — **не** запускайте их двойным кликом сами: на многих компьютерах
скрипты запрещены, и окно закрывается раньше, чем успеваешь прочитать
сообщение, — и программа кажется сломанной. Файл `.cmd` обходит обе проблемы.
(Добавлено Casto, который именно на этом споткнулся.)

**Обычный способ** не требует подготовки. Если Node.js нет, установка загружает его
сама — в портативном виде в папку проекта, без записи в систему и
без прав администратора.

**Сначала вопрос «куда».** Если на вашем компьютере уже лежит архив — в том числе старый
*MySuno*, как бы ни называлась его папка, — он будет найден и предложен первым: тогда обновляется только программа, а ваши треки, изображения и
аудиофайлы остаются. Поиск идёт рядом с распакованной папкой, в
папке пользователя, в «Загрузках», на рабочем столе, в «Документах» и «Музыке», на
два уровня вглубь; архив определяется по каталогу, а не по названию. Если ваш старый архив
лежит на другом диске, вы сами выбираете папку через «В другое место».

**Затем десять этапов, и каждый сообщает, что делает:**

1. Проверка папки — право записи, отсутствие прав администратора, место (около 1,6 ГБ).
2. Что уже есть? Архив, ffmpeg, пакеты, модели ИИ, порт — с размерами; видно, что
   отсутствует и будет загружено. После этого понятно, чего ждать.
3. ffmpeg — в Windows загружается, на Mac и Linux ставится через менеджер пакетов.
4. Компоненты сервера (19 пакетов).
5. Модели ИИ (16 файлов, около 1,2 ГБ).
6. Ваше имя в Suno — единственный ввод.
7. Ваш список треков: названия, тексты, стили, альбомы.
8. Уже скачанные файлы Suno распознаются и упорядочиваются.
9. Обложки и видео. Самый долгий этап — и единственный, который спокойно можно прервать:
   «Запустить сейчас, остальное позже» догружает остальное во время работы.
10. В конце: то, что можете получить только вы сами, и почему.

Прервать можно в любой момент; при следующем запуске догружается только то, чего не хватает.
Если что-то застряло, на вкладке **Журнал** всё написано обычным текстом.

Все адреса загрузки перечислены в [`quellen.txt`](quellen.txt), по строке на каждый
компонент. Если поставщик переезжает, правят строку там — и никому не нужно искать
по скриптам.

**Путь через Docker** — для тех, кто не хочет ничего устанавливать: Node и
ffmpeg тогда лежат в контейнере, и на вашем компьютере от них ничего не остаётся.
Ваш архив при этом всё равно остаётся снаружи, на диске (`library/`) — контейнер
можно выбросить и собрать заново, музыка останется. И с этого момента он сам запускается
вместе с компьютером.

Одного контейнер не видит: папки вашего компьютера. Если ваши
файлы Suno уже где-то лежат, кнопка «Выбрать папку…» открывает поэтому окно выбора папки
вашего браузера — страница распознаёт файлы по содержимому и берёт то, чего
не хватает. Выбранную так папку KlangTresor не запоминает; если позже там появится
что-то новое, выберите её ещё раз.

Нужен только Docker — а какой именно, зависит от системы.
**Скрипт подскажет**, если его нет: на Mac — версию для вашего
процессора (Apple Silicon или Intel), в Windows сначала WSL 2, а потом Docker
Desktop, в Linux — Docker **Engine** (не Desktop) вместе с двумя
шагами, о которых там любят забывать: запустить службу и добавить себя
в группу `docker`. Если Docker есть, но не запущен, скрипт предлагает
запустить его и подождать.

После запуска Docker вы продолжаете **в браузере**: вверху справа
введите псевдоним, затем нажмите красную кнопку — она получает список треков, загружает
медиафайлы и рассчитывает анализ. Терминал после этого вам не нужен.

Если вы предпочитаете идти шаг за шагом или хотите знать, что делают скрипты,
просто читайте дальше — они делают ровно то, что написано ниже.

## Что вам нужно

- [**Node.js**](https://nodejs.org) — достаточно версии LTS (от 20)
- [**ffmpeg**](https://ffmpeg.org) — Mac: `brew install ffmpeg`,
  Linux: `sudo apt install ffmpeg` (или ваш менеджер пакетов),
  Windows: `winget install ffmpeg` (или с ffmpeg.org, затем папку
  `bin` — в PATH) — после этого заново откройте терминал
- Место на диске: около 15 МБ на трек, с WAV около 70 МБ

Один раз в распакованной папке — это загружает единственный пакет, который нужен
программе (среду выполнения ИИ для звукового пространства), и модели:

```bash
npm install
node bin/modelle-holen.js
```

Больше ничего: ни базы данных, ни Python, ни Docker. Одинаково работает на Mac,
Linux и Windows (PowerShell).

Если при загрузке моделей появляется «fetch failed», ваш компьютер не достаёт до
источников (прокси, сертификат, DNS). Тогда скрипт пробует сам через
`curl`, а если не выходит, говорит точно, какие файлы вам нужно открыть в браузере и
под каким именем сохранить в `library/modelle/` —
затем снова `node bin/modelle-holen.js`, уже имеющееся пропускается.

Браузер для начала вам **больше не нужен**.

## Шаг 1 — Сбор

Откройте терминал в распакованной папке, затем — **вместо `dein-handle` подставьте
имя после `@` на вашей странице профиля Suno**:

```bash
node bin/sammeln.js dein-handle
```

Вот и всё. Не нужно входить в аккаунт, не нужна консоль браузера, ничего не нужно копировать: интерфейс
профиля Suno отвечает без токена и отдаёт полные
данные треков вместе с текстами. Исходный файл программа сама кладёт в нужное
место.

В конце она сообщает, что нашла, — а при втором запуске ещё и то,
что **нового** по сравнению с уже имеющимся у вас.

---

## Шаг 2 — Сборка всего

```bash
node bin/wiederherstellen.js
```

Это загружает ваши MP3 и обложки с сервера Suno, рассчитывает плитки
и извлекает из каждой обложки цветовую палитру. В зависимости от размера коллекции
это занимает несколько минут. Процесс можно прервать в любой момент и запустить снова —
догружается только то, чего не хватает.

## Шаг 3 — Слушать

```bash
node server/server.js
```

Или двойным кликом по ярлыку «KlangTresor» на рабочем столе —
либо по **`starten-windows.cmd`**, **`starten-macos.command`**,
**`starten-linux.sh`** в папке: то же самое, только без набора команд.

Адреса указаны в выводе: на самом компьютере
`http://localhost:8788`, на iPhone и iPad — адрес с
цифрами. Оба устройства должны быть в одной сети Wi-Fi. Завершить можно клавишами `Ctrl+C`.

**Окно остаётся открытым, пока вы слушаете.** В нём работает сервер;
если закрыть окно, сервер завершится — а вместе с ним и всё, что красная кнопка
в этот момент рассчитывает. Свернуть окно можно.

**Клавиатура:** пробел ставит на паузу, стрелка влево/вправо переключает трек,
стрелка вверх/вниз меняет громкость, `m` отключает звук. На сцене дополнительно `f` —
полноэкранный режим и `Esc` — закрыть.

**В нижней панели** слева находятся «Назад», «Воспроизвести» и «Вперёд», затем
плитка и название, затем «Перемешать» и «Повторять», громкость, а справа —
три кнопки для сцены:

| | |
|---|---|
| **Микрофон** | Караоке — текст идёт точно по словам |
| **Текстовый блок** | Текст песни — весь трек на разделённом экране |
| **Столбики** | Анализ — см. ниже |

Клик по **плитке** открывает сцену в том виде, в каком вы оставили её в прошлый раз.
Если кнопка серая, у трека нет необходимого: без временных меток слов нет караоке,
без текста нет текста песни.

**Whisper, ваше пожелание:** для треков, к которым Suno не даёт временных меток,
KlangTresor рассчитывает их сам с Whisper `large-v3` — за ночь, начиная
с самых новых. Если на кнопке написано «Караоке (Whisper)», значит, метки
получены на слух, а не выровнены Suno. Как настроить это на вашей машине
(с GPU заметно быстрее): `docs/suno/WHISPER.md`.

## По желанию — оригиналы WAV

Suno держит для каждого трека и версию без потерь, но
только после того, как её один раз запросили. Есть ли она уже, показывает:

> **С 03.09.2026 это больше не работает.** `bin/wav.js` получает WAV через
> `cdn1.suno.ai/<id>.wav`, и этот путь закрыт — как и все прямые ссылки на аудио
> у Suno, даже для владельца. Поэтому скрипт сейчас неактивен. Ответ **403**
> сегодня как раз означает «заблокировано». За этим следит `bin/gesundheit.js`,
> текущее состояние описано в `docs/suno/AUDIO-BEZUG.md`. Раздел ниже описывает
> состояние на август и остаётся как отчёт.

```bash
node bin/wav.js --pruefen
node bin/wav.js              # загружает всё, что готово
```

Как запросить недостающие, описано в `WAV-PROTOKOLL.md` — для этого один раз
понадобится браузер. Один WAV весит около 50 МБ; на сцене
вверху можно переключаться между MP3 и WAV.

## Режим анализа

Третья кнопка сцены открывает анализ текущего трека. Он
считается на вашем компьютере и нигде в сети ничего не запрашивает.

Вверху находятся **предложения по улучшению на основе данных**, переключаемые
по платформам — стриминг, Spotify, Apple Music, YouTube, клуб,
радио. Они сопоставляют то, чего требует платформа, и то, что есть
у вашего трека: громкость, пик, разброс, полные уровни
(клиппинг), фаза.

Две вещи, которые легко перепутать:

**Меньше минус — значит громче.** −11,8 LUFS выше цели в −14,
а не ниже. Запас до перегрузки — другая
величина: True Peak.

**Слишком громко при стриминге — не ошибка.** При воспроизведении трек
делается тише. Потеряна только динамика, которую раньше
обменяли на лимитер.

Ниже — **шкала времени с находками**: где пики выше цели,
где фаза гасится, где какой-то тон постоянно
выделяется — каждая отметка кликабельна, трек перематывается туда. Самая
верхняя дорожка показывает разделы вашего текста в цветах редактора
Suno.

Ещё ниже — кривые громкости, энергии, динамики, темпа, высоты тона,
стереокартины и две спектрограммы. У каждой кривой внизу можно настроить
профиль весов и длину окна — маленькие значки
показывают саму форму окна.

## Что делает закладка

Об этом спрашивают постоянно: собственные **неопубликованные** треки Suno отдаёт только
тому, кто вошёл в аккаунт. Программа на вашем компьютере — не такой пользователь: ключ входа
принадлежит браузеру и адресу `suno.com`, и Suno не разрешает ни одной
чужой странице его читать.

Поэтому закладка работает **во вкладке Suno**, там, где ключ
и так находится. С его помощью она получает список ваших треков вместе с адресами
и отправляет его в ваш KlangTresor. Всё остальное — музыку, обложки, видео — красная
кнопка загружает уже сама, потому что эти адреса работают и без входа в аккаунт,
если их знать.

Это **улица с односторонним движением**: закладка только читает. В Suno ничего не возвращается,
в том числе счётчики прослушиваний.

Если появляется сообщение, что вход недоступен: закладка
должна быть запущена на вкладке **suno.com** (не KlangTresor), страница должна полностью
загрузиться, и вы должны быть там авторизованы. С 23.08.2026 закладка ждёт
входа до восьми секунд, а не сдаётся сразу.

## Позже: догрузка новых треков — красная кнопка

В представлении альбомов вверху справа находится **красная кнопка**. Нажимайте её
по утрам:

1. Она запрашивает Suno и показывает, **что изменилось**:
   новые треки, изменённые, а также у каких появились новые прослушивания, лайки или комментарии.
   С плиткой и числом. При этом ещё ничего не меняется.
2. Ниже — **список выбора**, что должен сделать запуск, в трёх
   группах: с входом в аккаунт (только через закладку), публичные данные Suno
   (комментарии, медиа), локально (каталог, анализ, Whisper, музыкальный стиль
   и звуковое пространство). Обычно всё включено.
3. **Применить** — и обновление загружается. Кнопка вращается, пока идёт
   работа; окно можно закрыть и продолжать слушать.

Терминал для этого больше не нужен. Две команды сверху
по-прежнему делают то же самое, если вам так удобнее.

**Чего кнопка не умеет**, потому что для этого нужен ваш вход в аккаунт: ваши
временные метки слов для караоке, приватные треки, плейлисты и список тех, кто поставил лайк вашим
трекам. Для этого есть **закладка** — кнопка
объясняет её и даёт адрес для копирования. Создайте её один раз в Chrome,
затем кликните на любой странице Suno, где вы вошли в аккаунт. Ваш пароль при этом
нигде не сохраняется.

## Пространства — ваш архив как звёздное небо

Третья вкладка. **Есть два пространства**, переключаются в верхней строке:

| | Близость означает | на основе чего |
|---|---|---|
| **Звук** | звучат похоже | звука |
| **Истории** | говорят о схожем | текстов песен |

Пространству историй **не нужен перевод**: модель отображает
более сотни языков в одно и то же пространство, немецкие и английские тексты
лежат рядом, если речь в них о схожем. Треков без текста
там нет — об этом сказано и в легенде. Его тематические группы
называются по **названиям мест** — словам из ваших собственных песен,
которые «живут» там, где расположена группа; группа без явного места называется
честно «(смешанная местность)». У пространства пометка **(бета)**: оно
молодое и ещё дорабатывается.

О звуковом пространстве подробнее: музыкальный ИИ (Discogs-EffNet, от специалистов
Essentia в Барселоне) прослушивает каждый трек целиком и присваивает ему
место в звуковом пространстве: близость = похожее звучание, независимо от стилевого промпта.
Кроме того, жанр, настроение и инструменты каждого трека. Из этого строится
звёздное небо в 3D — кликните по звезде, и трек зазвучит; «Начать путешествие» заставляет
звуковой корабль лететь от соседа к соседу.

Рассчитывает это красная кнопка (этап «Музыкальный стиль и карта музыки»,
около 6–10 секунд на трек на процессоре) либо вручную:

```bash
node bin/klang.js
node bin/karte.js
```

Если у вас **карта NVIDIA** (Linux или Windows, установлены CUDA 12 + cuDNN 9),
команда `KLANG_CUDA=1 node bin/klang.js` считает на GPU —
заметно быстрее; в PowerShell: `$env:KLANG_CUDA=1; node bin/klang.js`.
Если не получается, программа сообщает об этом и переходит на процессор.

«Экспорт» на панели звукового пространства записывает `library/export/sternenhimmel.html` —
один-единственный файл с плеером, который можно отправить кому-то; в нём показаны
только публичные треки, и он работает без сервера (звук и обложки берутся
с Suno).

## Временные метки караоке с Whisper (по желанию)

Собственные временные метки слов Suno приходят через закладку. Для треков,
у которых их нет (или как вторую дорожку), программа рассчитывает их сама с помощью
[whisper.cpp](https://github.com/ggml-org/whisper.cpp) — его нужно
один раз собрать и сообщить программе, где он лежит:

```bash
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp && cmake -B build -DGGML_CUDA=1 && cmake --build build -j
sh ./models/download-ggml-model.sh large-v3
```

(`-DGGML_CUDA=1` только с картой NVIDIA — тогда трек обрабатывается за
секунды, а не за минуты; без карты опустите.) Затем перед запуском:

```bash
export WHISPER_CLI=/pfad/zu/whisper.cpp/build/bin/whisper-cli
export WHISPER_MODELL=/pfad/zu/whisper.cpp/models/ggml-large-v3.bin
```

В Windows (PowerShell) вместо этого:

```powershell
$env:WHISPER_CLI="C:\pfad\zu\whisper.cpp\build\bin\Release\whisper-cli.exe"
$env:WHISPER_MODELL="C:\pfad\zu\whisper.cpp\models\ggml-large-v3.bin"
```

Если Whisper нет, красная кнопка пропускает этот этап с сообщением —
всё остальное работает.

## Кто слушает — лайки и комментарии

На каждой плитке теперь есть **большой палец** и **облачко речи**
с числами. Кликните по ним, и у курсора откроется окно: динамика
прослушиваний, лайков и комментариев по дням, кто поставил
лайк (насколько это раскрывает Suno — за последние четыре недели) и **все
комментарии с ответами**, полным текстом, с эмодзи. Клик по
имени покажет, где ещё комментировал этот человек.

Комментарии сохраняются при каждом утреннем запуске — даже если
кто-то позже удалит свой, у вас он останется.

## Сортировка и поиск

В **меню сортировки** теперь есть и то, что программа измерила
по звуку: сначала быстрые, сначала медленные, сначала громкие, сначала динамичные,
шире стерео … Эти пункты появляются, только когда ваши треки один раз
проанализированы — это происходит само при утреннем запуске.

Рядом с **полем поиска** находится небольшое меню **Фильтр**. Оно знает:
модель, тональность, мажор/минор, голос, год, месяц, кто комментировал,
и чего ещё не хватает. Выберите ключ — и вам предложат только те
значения, которые действительно есть в вашем архиве, с количеством.
Клик подставляет значение в поле; несколько значений можно сочетать.

## Что стоит сохранять

**`library/katalog.json.gz`** — около 47 МБ. Там хранится всё, что
нельзя восстановить из файла: тексты песен, временные метки, комментарии, история
счётчиков, плейлисты. Кроме того, `library/roh/`, если там сейчас
что-то лежит: эта папка обычно пуста, потому что `aufbereiten.js` удаляет
обработанные исходные данные, как только их содержимое попадает в каталог.

## Две вещи, которые стоит знать

**Треки других людей в ваших плейлистах** не копируются,
а при воспроизведении берутся прямо с Suno. Они помечены словом **remote**
и требуют интернета. Всё, что принадлежит вам, лежит
локально и работает и без сети.

**Неопубликованные собственные треки** попадают в архив, если они находятся
в одном из ваших плейлистов. Они имеют пометку **приватный**, а в фильтре вверху
можно выбрать между *Публичные*, *Приватные* и *Все*.

## Если что-то не работает

- **`sammeln.js` ничего не находит:** значит, имя указано неверно — оно должно
  быть написано точно так, как после `@` на вашей странице профиля,
  без самого `@`.
- **Не хватает треков:** запустите ещё раз — Suno ограничивает частоту при слишком
  быстрых запросах, программа это замечает и сообщает вам.
- **iPhone не открывает страницу:** оба устройства в одной сети Wi-Fi?
  И при первом запуске брандмауэр компьютера спрашивает, можно ли Node
  принимать подключения, — это нужно разрешить (в Windows оставьте
  «Частные сети» и нажмите «Разрешить доступ»).
- **Suno что-то изменил:** выполните `browser/01-erkundung.js` в
  консоли браузера; он покажет, какие интерфейсы ещё
  отвечают.
- **npm предупреждает «install scripts not yet covered by allowScripts»:**
  это не ошибка, и ничего не пропало. Начиная с npm 11 npm хочет знать, каким
  пакетам разрешено выполнять собственные скрипты при установке, — следствие
  атак через пакеты npm. У KlangTresor такой пакет ровно один:
  `onnxruntime-node` с его помощью загружает среду выполнения ИИ для
  звукового пространства. Разрешение записано в `package.json`
  с 27.08.2026. Если вы всё равно видите это сообщение, у вас более старая версия —
  загрузите её заново или один раз выполните
  `npm approve-scripts onnxruntime-node`. В npm 11 всё
  работает, это всего лишь предупреждение; начиная с npm 12 без разрешения
  npm блокирует установку.
