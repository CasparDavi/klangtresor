# Eingang

Hier liegt Rohmaterial, das ins Repo gehört, aber noch nicht eingearbeitet
ist: Gesprächsauszüge, Notizen, Fundstücke. Zweck des Ordners ist, dass
nichts verlorengeht, nur weil gerade keine Lust auf Aufräumen ist.

**Regel:** Jede Datei trägt im Kopf einen Status.

- `OFFEN` — Rohtext liegt da, niemand hat ihn ausgewertet
- `IN ARBEIT` — wird gerade in die Dokumente verteilt
- `ERLEDIGT — <wohin>` — der Inhalt steht jetzt in HISTORY, BACKLOG,
  OFFEN oder wo auch immer; die Rohdatei bleibt als Beleg liegen

Wer eine Datei auswertet, verteilt den Inhalt an die richtige Stelle und
setzt hier den Status. Der Ordner soll leer wirken, nicht voll.
