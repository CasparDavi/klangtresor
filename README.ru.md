# KlangTresor

**Твоя музыка из Suno. У тебя дома.**
Suno создаёт песни. KlangTresor хранит их, играет, измеряет и показывает — на любом экране в твоём доме.
Свободно и с открытым кодом. Без учётной записи. Работает на твоём собственном компьютере.

**Системные требования.** 64-битный компьютер с Windows 10 или 11, macOS 11 или новее либо Linux (x86_64). Около
5 ГБ свободного места для программы и моделей ИИ, плюс примерно 15 МБ на песню (с оригиналом WAV — около 70 МБ).
Современный браузер — для полной функциональности **Google Chrome**; для прослушивания подойдёт любой телефон, планшет
или телевизор в домашней сети.

## Что он умеет

<a href="https://caspardavi.github.io/klangtresor/features/?lang=ru"><img src="docs/features/img/readme-quartett-ru.jpg" alt="Любой экран дома, настоящая студия в браузере, пространство звука, сцена" width="100%"></a>

- **Твой архив.** Каждая песня, которую ты сделал в Suno, — MP3 и WAV, тексты, обложки, живые обложки, плейлисты,
  комментарии и лайки — в папке на твоём собственном компьютере.
- **Сцена для каждой песни.** Караоке, где текст идёт слово за словом, визуализации в цветах обложки, полный экран на
  телевизоре.
- **Настоящая студия в браузере.** 8-полосный эквалайзер, компрессор и пространство, откалиброванные на месте
  прослушивания.
- **Взгляд внутрь песен.** Громкость, тональность, диапазон голоса, шесть разделённых инструментальных дорожек — и
  звёздная карта, которая упорядочивает всю коллекцию по звучанию или по смыслу.
- **Сделай из этого что-то.** Студия плакатов для всего творчества, эффект-клипы из неподвижной обложки, экспорт на
  флешку или в папку с музыкой для машины.

## Первые шаги

1. **Скачай и открой** файл для своей системы. Установщики пока не подписаны, поэтому при первом запуске система
   один раз переспросит:
   - **Windows:** «Система Windows защитила ваш компьютер» → *Подробнее* → *Выполнить в любом случае*. Edge может
     сначала попросить *сохранить* загрузку.
   - **macOS:** если запуск заблокирован: Системные настройки → Конфиденциальность и безопасность → *Всё равно открыть*.
   - **Linux:** правый клик → Свойства → разрешить *Выполнять как программу*, затем двойной щелчок. Без sudo.

   [START-RU.md](START-RU.md) показывает каждый щелчок с картинками.
2. **Установка идёт в браузере.** Она загружает ffmpeg и модели ИИ с индикатором, спрашивает твоё имя в Suno и
   собирает твои публичные песни.
3. **KlangTresor работает как значок** на панели задач, в Dock или на панели. Страница открывается по адресу
   **http://localhost:8788**. Для телефона, планшета и телевизора в той же сети Wi-Fi раздел
   *Профиль → На телефоне* показывает адрес и QR-код.
4. **Закрытые песни, альбомы и пословные метки времени** требуют входа в Suno. KlangTresor никогда не видит твой
   пароль: закладка, которую ты нажимаешь в своей вкладке Suno, передаёт их сама. Её адрес — в утреннем окне за
   красной кнопкой.

Дальше **красная кнопка** справа вверху забирает всё новое.

## Обновление и резервная копия

- **Обновление:** когда выходит новая версия, рядом с красной кнопкой появляется колокольчик. Один щелчок
  устанавливает её прямо в приложении; более новый установщик делает то же самое. Архив не затрагивается.
- **Резервная копия:** сохраняй **`library/katalog.json.gz`** в папке KlangTresor. В нём то, что нельзя загрузить
  заново: тексты, пословные метки, комментарии, плейлисты, история счётчиков. Всё остальное (медиа, обложки, анализы)
  восстанавливает `node bin/wiederherstellen.js`. Инструментальные дорожки пересчитает утренний запуск; оригиналы WAV
  не вернутся — кто хочет их сохранить, копирует и `library/songs/`.

## Твои данные

Твои песни остаются на твоём компьютере. У KlangTresor нет учётной записи, облака и слежки. В сеть он выходит только
чтобы забрать твои песни из Suno, загрузить инструменты и модели при установке и спросить у GitHub, нет ли новой
версии.

## Вопросы

<details><summary><b>Телефон не открывает страницу.</b></summary>

Телефон и компьютер должны быть в одной сети Wi-Fi. При первом запуске брандмауэр компьютера спрашивает, может ли Node
принимать подключения, — разреши.
</details>

<details><summary><b>Windows или macOS пишет, что приложение небезопасно.</b></summary>

Установщики пока не подписаны. Подтверди один раз, как описано в разделе [Первые шаги](#первые-шаги).
</details>

<details><summary><b>«Порт 8788 уже занят».</b></summary>

Уже работает другой KlangTresor. Заверши его через значок или открой http://localhost:8788 и проверь, тот ли это
архив.
</details>

<details><summary><b>Во время установки не удалась загрузка.</b></summary>

Установка говорит, чего не хватает, и предлагает попробовать снова. KlangTresor работает и без этого; недостающие
модели можно загрузить позже в разделе *Профиль → Система*.
</details>

<details><summary><b>Как его удалить?</b></summary>

Windows: Параметры → Приложения → KlangTresor. macOS: перетащи приложение в Корзину. Linux: удали AppImage. Архив и
модели ИИ остаются в папке `KlangTresor` в твоей домашней папке — удали её, если хочешь убрать всё.
</details>

## Полезно знать

- **Не клиент Suno.** Публичное забирается публично, остальное — в твоей собственной вкладке Suno, где ты вошёл.
  Он собирает только твои песни.
- **Не связан с Suno Inc.** Suno — товарный знак Suno Inc. До августа 2026 года программа называлась *MySuno*.
- **Он следует за Suno.** Если Suno изменит сайт, утреннему запуску может понадобиться новая версия. Всё, что уже
  дома, продолжает играть.
- **Проверено** на Windows 10 и 11, macOS 26 (Intel) и Ubuntu 24.04. Apple Silicon поддерживается, но ещё не
  проверен на реальном устройстве.

<details><summary><b>Другие способы установки</b> — zip, Docker, Git, WSL</summary>

- **Zip:** скачай `KlangTresor.zip` из [последнего выпуска](https://github.com/CasparDavi/klangtresor/releases/latest),
  распакуй и дважды щёлкни `einrichten-windows.cmd`, `einrichten-macos.command` или `einrichten-linux.sh`.
- **Docker:** то же с `einrichten-docker-*` — всё работает в контейнере, `library/` остаётся на твоём диске.
- **Git:** `git clone https://github.com/CasparDavi/klangtresor && cd klangtresor && npm ci && npm start`.
- **Обновление** таких установок: колокольчик в приложении или `aktualisieren-*` в папке программы.
- **WSL:** браузер тоже должен работать в WSL, иначе закладка не найдёт сервер.

Подробности: [docs/INSTALL-ADVANCED.md](docs/INSTALL-ADVANCED.md) (на английском).
</details>

<details><summary><b>Переход с MySuno или с версии 1.0.72 и старше</b></summary>

В этих версиях ещё нет скрипта обновления. Скопируй `aktualisieren.js` и скрипт для своей системы из
[KlangTresor-Update.zip](https://github.com/CasparDavi/klangtresor/releases/latest/download/KlangTresor-Update.zip)
в папку, где лежит `library/`, и запусти его. Архив и настройки сохраняются; анализы один раз пересчитываются.
Подробности: [docs/MIGRATION-MYSUNO.md](docs/MIGRATION-MYSUNO.md) (на английском).
</details>

<details><summary><b>Для разработчиков</b></summary>

```
git clone https://github.com/CasparDavi/klangtresor && cd klangtresor && npm ci
npm start                      # server/server.js → http://localhost:8788
```

Node 20 или новее; две зависимости (`onnxruntime-node`, `umap-js`). Структура: `server/` сервер для домашней сети ·
`web/` интерфейс · `bin/` сбор, измерения, установка, обновление · `browser/` закладка · `docker/`.
Установщики: `node bin/paket.js` собирает zip, Setup.exe, AppImage и DMG. Документация в основном на немецком:
[docs/LIESMICH.md](docs/LIESMICH.md).

Почему что-то устроено именно так, обычно написано комментарием прямо в исходном коде.
</details>
